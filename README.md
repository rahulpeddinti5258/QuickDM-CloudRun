# QuickDM 📩

**Instagram Comment-to-DM Automation**

QuickDM is an Instagram automation project designed to help creators and businesses engage with their audience by automatically responding to comments and sending direct messages.

The goal is to make audience engagement faster, simpler, and more efficient.

## ✨ Features

- **Automatic Comment Replies:** Automatically reply to Instagram comments.
- **Automated Direct Messages:** Send personalized DMs to users who interact with posts.
- **Duplicate Protection:** Prevent repeated processing of the same comment using persistent tracking.
- **Webhook Integration:** Receive Instagram events through Meta Webhooks.
- **Cloud Deployment:** Designed to run on Google Cloud Run.
- **Extensible Workflows:** Built to support additional engagement automation.

## ⚙️ Tech Stack

- Python
- Flask
- Instagram Graph API / Meta Platform
- Meta Webhooks
- SQLite
- Google Cloud Run
- GitHub

## 🚀 Project Status

QuickDM is actively under development.

The initial comment-reply and DM automation functionality has been developed. Cloud deployment, reliability improvements, and additional automation workflows are part of ongoing development.

## 🔒 Security

- Never commit API access tokens, app secrets, or webhook secrets.
- Store sensitive credentials in environment variables or a secure secret manager.
- Keep private configuration files out of version control.
- Follow Meta's Instagram Platform policies and messaging requirements.
